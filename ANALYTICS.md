# HesLab PostHog Analytics

The full analytics and event taxonomy documentation is located in:
👉 [**docs/ANALYTICS.md**](./docs/ANALYTICS.md)

### Quick Start:
1. Copy `.env.example` to `.env` and fill in `VITE_PUBLIC_POSTHOG_KEY`.
2. Run automated analytics tests: `npm run test:analytics`.
3. Dev server runs with console event logging automatically enabled in development mode.
